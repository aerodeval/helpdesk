== integrations | sundial-bookkeeping/deborah | Medium | Done
# QuickBooks sync creating duplicate customers
C: Hello,

I connected a client's Fernbill account to QuickBooks Online last week. Every invoice that syncs creates a new customer in QuickBooks instead of matching the existing one. We now have "Acme Plumbing", "Acme Plumbing 1", "Acme Plumbing 2" and so on.

Deborah Klein
A kwame: Hi Deborah,

Thanks, this one is common on a first connection. Fernbill matches customers by email address first and display name second. The existing QuickBooks customers don't have an email on file, and the Fernbill clients do, so no match is found and a new customer is created.

The fix:
1. Pause the sync under Settings > Integrations > QuickBooks.
2. Use Map customers on the same page to link each Fernbill client to the right QuickBooks customer. It suggests matches by name.
3. Merge the duplicates in QuickBooks (Customers > select > Merge).
4. Resume the sync.

New invoices will then go to the right customer.

Kwame
C: That's done and the last few invoices synced correctly. Thank you, clear instructions.

== integrations | bluefin-analytics/arjun | Medium | Done
# API: how to filter invoices by updated date
C: Using the API to sync invoices into our warehouse. GET /v3/invoices returns everything every time. Is there a filter for invoices changed since a timestamp?
A yuki: Hi Arjun,

Yes, use updated_since with an ISO 8601 timestamp, for example:

GET /v3/invoices?updated_since=2025-10-01T00:00:00Z

It includes invoices whose status, payments or line items changed after that time. Combine it with the cursor parameter for pagination, and keep the last updated_at you saw as the next starting point.

Yuki
